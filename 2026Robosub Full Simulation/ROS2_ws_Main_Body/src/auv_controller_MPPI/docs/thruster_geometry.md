## 3. 1 m 统一缩放

任务书假设艇长 1 m → 三轴统一缩放系数(不做各向异性缩放):

```
s = 1.0 / 0.6975 = 1.433692
```

缩放后艇体:0.825(x) × 0.519(y) × 1.000(z) m;排水体积 ×s³ = 0.03949 m³
→ 浮力 ρgV = 387.4 N,对比重量 40×9.81 = 392.4 N(近中性,略沉)。

| t4 | (−0.3494, +0.0374, −0.1700) |
| t5 | (−0.3494, +0.0374, +0.1956) |
| t6 | (+0.3416, +0.0374, +0.1956) |
| t7 | (+0.3416, +0.0374, −0.1700) |

布局特征:水平组 t0–t3 位于质心平面**下方 9.2 cm**,垂直组 t4–t7 在质心平面
**上方 3.7 cm**(4+4 矢量布局)。

坐标系约定(重要,与 REP 103 不同):**+x 左舷/侧向,+y 上,+z 前**;
roll 绕 z、pitch 绕 x、yaw 绕 y。原因:Isaac base_link 的 twist 即此约定。
世界系竖直轴向参数化(`dynamics.world_up`,默认 z-up,Isaac 直通场景配 y-up),
见 config/mppi.yaml 注释。

## 5. 分配矩阵 B(6×8)

第 i 列 = [d_i ; r_i × d_i],d_i 为单位推力方向:

```
B = [ 0.7071  -0.7071  -0.7071   0.7071   0       0        0       0     ]   Fx(体-x)
    [ 0        0        0        0        1       1        1       1     ]   Fy(体-y)
    [ 0.7071   0.7071  -0.7071  -0.7071   0       0        0       0     ]   Fz(体-z,前进)
    [-0.0648  -0.0648   0.0648   0.0648   0.1700 -0.1955  -0.1955  0.1700]   Mx(滚转)
    [ 0.5192  -0.5269   0.5119  -0.5041   0       0        0       0     ]   My(俯仰)
    [ 0.0648  -0.0648  -0.0648   0.0648  -0.3494 -0.3494   0.3416   0.3416]   Mz(偏航)
```

**秩与条件数(JacobiSVD,节点启动时同样检查,失败即 FATAL 退出):**

| 指标 | 值 |
|---|---|
| rank | **6(满秩,6-DOF 完全可控)** |
| 奇异值(降序) | 2.0002, 1.4221, 1.4206, 1.0309, 0.6873, 0.3639 |
| 条件数 | 5.496 |
| 最小范数分配回代误差 | ~1e-16(B⁺B = I 验证) |

结论:该 4+4 矢量布局对 6 个广义方向均可控;最弱方向(σmin=0.3639)为
滚转/垂直耦合方向(垂直组 x 向力臂 0.34–0.35 m 造成)。

## 6. 推力极限

4000 gf = 4.0 kgf × 9.80665 m/s² = **39.2266 N**,正反对称
(`thrusters.force_min/max`)。未做推力-转速曲线建模,全局缩放因子
`dynamics.thrust_scale` 留给系统辨识。
